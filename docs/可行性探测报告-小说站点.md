# 小说站点可行性探测报告

**探测时间**：2026-10-26 22:00
**探测方式**：后台无头浏览器 + curl（不占前台焦点）
**目的**：找出「能做、难度适中、不碰 DRM」的小说抓取目标

# 一、番茄小说 —— ⚠️ 三重反爬，成本最高

## 1.1 实测数据

| 探测项 | 结果 |
|---|---|
| 首页 `fanqienovel.com` | HTTP 200, 163 KB, 0.35s |
| 书籍页 `/page/{id}` | HTTP 200, 476 KB |
| 章节页 `/reader/{id}` | HTTP 200, 38 KB |
| 章节链接 | ✅ 能从书籍页取到 |
| **正文** | ❌ **686 个私有区字符**（`U+E516` 这类） |

## 1.2 三大反爬机制

### ① 字体混淆（最狠）

```
页面里 6 个 @font-face，指向自定义 woff2 字体：
  https://lf6-awef.bytetos.com/obj/awesome-font/c/dc027189e0ba4cd.woff2  (47 KB)

字体内部映射：
  U+E3E8 → gid58344    ← 指向字形 ID，不是字符
  U+E3E9 → gid58345
  ...
  共 362 条映射

字体是 CFF 轮廓（不是 glyf），必须渲染成图像才能识别
```

**真实文字还原的唯一方法**：把每个 glyph 渲染成图片 → **OCR 识别** → 建映射字典。

### ② `a_bogus` 签名

跟抖音同一套（字节系），调 API 要算签名。

### ③ `msToken`

搜索接口需要，过期很快。

## 1.3 现成开源方案

| 项目 | 方案 | 说明 |
|---|---|---|
| [fanqienovel-decryptor](https://github.com/romcere/fanqienovel-decryptor) | 内置映射字典 | 字体换了就失效 |
| [FanqieFetch](https://github.com/hxhy00/FanqieFetch) | **woff→jpg→OCR** | 自动化，带人工校对 GUI |
| [noval-ranks-mcp-server](https://github.com/Logan66666/noval-ranks-mcp-server) | 自定义字库解码 | 偏榜单 |
| [font-decoder](https://github.com/hjdhnx/font-decoder) | 图像 + OCR | 通用字体解密 |

**思路验证完成：这条路走得通，但需要 OCR 引擎 + 字体渲染。**

## 1.4 成本估算

| 环节 | 工作量 |
|---|---|
| woff2 → 字形图片（需要 fontTools + 渲染库） | 1 天 |
| 字形图片 → OCR → 映射字典 | 1.5 天 |
| 映射缓存 + 版本管理（字体常换） | 1 天 |
| a_bogus / msToken 签名 | 1.5 天 |
| 章节抓取 + 断点续传 | 2 天 |
| **合计** | **约 7 天** |

## 1.5 结论

**能做，但成本最高。** 建议**先做简单目标验证市场，最后再做番茄**。

## 3.3 需要注意的问题

# 六、建议的执行顺序

## 第一期：笔趣阁系（2.5 天）

**理由**：
- 零反爬，结构最干净
- 一次抓通，就能验证「小说下载」这个市场
- 域名池可以写死 3~5 个备用

**技术路线**：
```
书籍页 /book/{id}/ → 正则提取章节列表
  ↓
章节页 /chapter/{id}/{cid}.html
  ↓
选择器 id="txt" → 提取正文
  ↓
清洗：去广告、去 &nbsp;、去页码标记
  ↓
输出：单章 .txt 或整本合并 .txt
```

## 第二期：17K（2 天）

摸清章节列表的加载方式（AJAX 接口或目录页）。

## 第三期：番茄小说（7 天）

**前置条件**：前两期验证了市场，确认有人买。

**技术路线**：
```
woff2 → fontTools 解析 → 渲染每个 glyph 为 PNG
  ↓
OCR 识别（PaddleOCR 或 tesseract）
  ↓
生成 {PUA码 → 真实字符} 映射字典
  ↓
页面正文替换 → 正常文本
  ↓
（可选）a_bogus 签名调 API
```

**风险**：字体定期更换，需要持续维护映射。

# 七、法律与产品边界

## 必须守住的三条

| 边界 | 说明 |
|---|---|
| **只做免费章节** | 付费章节不碰（需要 VIP 账号） |
| **不内置任何书源** | 用户自己粘链接 |
| **不做批量爬全站** | 单本下载合理，全站爬取是侵权 |

## 免责声明要加的内容

```
本功能仅用于抓取公开可访问的免费章节内容，
供个人学习、备份、离线阅读使用。

不支持、不提供任何付费章节、VIP 内容、会员专享内容的获取。

下载内容的著作权归原作者及原发布平台所有，
请勿二次分发、上传至其他平台或用于商业用途。
```
