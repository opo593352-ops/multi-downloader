## 一、清理掉的东西

### 1. `ffmpeg-9.0.2/` — 105 MB，10399 个文件

**是什么**：FFmpeg 源码解压残留（`configure`、`Makefile`、`COPYING.*` 那些）。

**为什么删**：项目只需要 `ffmpeg.exe` 二进制，源码从没被引用过。已确认 `grep -rn "ffmpeg-9.0.2"` 零结果。

**去向**：`_归档/构建残留/ffmpeg-9.0.2/`

### 2. `src/tools/ffmpeg.exe` — 84 MB

**是什么**：根目录 `ffmpeg.exe` 的副本。

**为什么删**：构建脚本早就不从这里取了（`build-all.cmd` 检查 `tools\ffmpeg.exe` 只是警告，实际用的是根目录那份）。

**去向**：`_归档/构建残留/ffmpeg-copy.exe`

### 3. `src/_t.docx` + `src/_t.txt` — 3 KB

**是什么**：`doc-export.mjs` 的测试样本（"测试标题 / 这是一段加粗和斜体还有代码的正文"）。

**为什么删**：功能已验收，样本用完了。

**去向**：`_归档/临时文件/`

### 4. `src/build/` 里的旧产物 — 约 400 KB，9 个文件

```
bundle.cjs            ← 10-23 的老 bundle
sea-prep.blob         ← 同上
music-*.bin/.cjs      ← 分体版音乐下载器（早已合并）
zhihu-*.bin/.cjs      ← 分体版知乎（早已合并）
internal-*            ← 内部版构建残留
cli-internal.mjs      ← 内部入口
```

**为什么删**：`cli.mjs` 合并成单引擎后，这些分体产物全部废弃。保留的只有：
```
all-blob.bin / all-bundle.cjs / all-bundle.raw.cjs      ← 发行版
beta-blob.bin / beta-bundle.cjs / beta-bundle.raw.cjs   ← 内测版
keygen-blob.bin / keygen-bundle.cjs                     ← 卡密生成器
```

**去向**：`_归档/构建残留/`

### 5. 测试输出 — 72 MB

```
downloads/文章/*      ← 知乎抓取的测试产物
downloads/抓取/*      ← 网页抓取的测试产物
logs/*.log / *.json   ← 运行日志
```

**为什么删**：都是测试时下的知乎文章和日志，不是项目文件。

**去向**：`_归档/测试输出/`

## 二、文档重新归类

